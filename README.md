# aliyun-mp-writer

> 阿里云官方微信公众号文章写作 Skill for QoderWork

将技术素材、产品文档、新闻稿等内容转化为符合阿里云官方微信公众号风格的专业文章。

## 简介

`aliyun-mp-writer` 是一个专为 [QoderWork](https://docs.qoder.com/qoderwork/introduction) 设计的 AI 写作 Skill，能够自动将各类素材（Word 文档、PDF、Markdown、在线链接或纯文本）整理并输出为符合阿里云官方微信公众号风格的原创文章。

该 Skill 深度提炼了阿里云官微文章的写作风格特征，包括：

- **理性务实与前瞻自信并重**的基调
- **「技术特性 + 业务价值」双段式**核心句型
- **「挑战 → 方案 → 效果」三段式**叙事框架
- **数据驱动**的技术 claim 表达
- 典型的阿里云「工程师气质」——严谨、克制、以数据说话

## 功能特性

- **多格式输入**：支持 Word (.docx)、PDF (.pdf)、Markdown (.md)、纯文本 (.txt) 及在线链接
- **智能内容提炼**：自动提取产品/技术、业务问题、核心能力、效果数据等关键信息
- **结构化输出**：按阿里云官微标准文章结构组织（标题 → 开篇 → 背景 → 痛点 → 方案 → 案例 → 展望）
- **风格自适应**：根据素材类型自动选择最合适的文章结构变体
- **多格式输出**：支持输出为 Word、PDF 或 Markdown 格式

## 安装

### 前置要求

- [QoderWork](https://docs.qoder.com/qoderwork/introduction) 桌面应用
- QoderWork 内置的 `docx`、`pdf` Skill（用于读取输入素材）

### 安装步骤

1. 下载或克隆本仓库到本地：
   ```bash
   git clone https://github.com/<your-username>/aliyun-mp-writer.git
   ```

2. 在 QoderWork 中安装该 Skill：
   - 打开 QoderWork 应用
   - 进入 Skills 管理界面
   - 选择「Install Skill」或「添加 Skill」
   - 指向本仓库的目录路径

3. 确认安装成功后即可使用。

## 使用方法

### 基本用法

在 QoderWork 对话中直接输入指令，例如：

```
帮我把这份产品文档写成阿里云微信公众号文章
```

然后附上你的素材文件路径或链接即可。

### 支持的输入格式

| 输入格式 | 说明 |
|----------|------|
| Word 文档 (.docx) | 自动使用 `docx` Skill 解析文本和表格 |
| PDF 文档 (.pdf) | 自动使用 `pdf` Skill 解析文本和表格 |
| Markdown (.md) | 直接读取并解析 |
| 纯文本 (.txt) | 直接读取并解析 |
| 在线链接 | 自动抓取网页内容 |
| 对话输入 | 直接在对话中粘贴的文本 |

### 输出格式

在对话中指定你期望的输出格式：

- 指定 **Word** 输出 → 生成 `.docx` 文件
- 指定 **PDF** 输出 → 生成 `.pdf` 文件
- 指定 **Markdown** 或未指定 → 默认输出 `.md` 文件

输出文件名格式：`aliyun-mp-{主题关键词}-{日期}.{扩展名}`

aliyun-mp-writer/

### 文件说明

| 文件 | 作用 |

| `SKILL.md` | Skill 的核心配置文件，包含工作流程、输入输出规则、格式要求 |
| `style-reference.md` | 详细的风格指南，涵盖词汇、句式、段落、结构、修辞等 11 个维度的规范 |
| `article-template.md` | 完整的文章骨架模板，包含各章节写作模板和标题拟定指南 |

## 文章结构

该 Skill 按照以下标准结构组织文章内容：

```
1. 标题：宣告式 + 核心价值
2. 开篇：宣告式开头 + 产品定位 + 核心价值
3. 业务背景：行业趋势、技术浪潮
4. 业务痛点：2-4 个核心挑战
5. 方案详解：分模块技术解读（挑战 → 方案 → 效果）
6. 客户案例：客户证言、效果数据
7. 未来展望：展望式结尾 + 行动号召
```

根据素材类型，可选择不同侧重的结构变体（产品发布型、客户案例型、行业解读型、技术深度型）。

## 风格特点

### 高频关键词

企业级、生产环境、极致、深度融合、一站式、全链路、开箱即用、规模化落地、赋能、助力

### 核心句型

```
通过 XXX 技术，实现 YYY 效果，从而 ZZZ 价值。
```

### 四大母题

每篇文章围绕以下至少一个母题展开：

1. **AI 原生**：大模型、智能体、Agent Infra
2. **云原生**：Serverless、容器、微服务
3. **企业级落地**：生产环境、安全隔离、高可用
4. **降本增效**：TCO、弹性、按量付费

1. 读取并解析你的文档
2. 提取核心技术信息和业务价值

4. 输出为指定的文件格式
